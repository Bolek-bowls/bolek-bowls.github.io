bólek, здоровое меню (боулы с КБЖУ)

Открыть: дважды щёлкнуть index.html.

Файлы
  index.html            главная со списком боулов
  shrimp.html           боул с креветками
  chicken.html          боул с курицей
  qr.html               страница для создания QR-кодов (на главной не показывается)
  data/bowls.js         ВСЕ цифры и составы. Меняем только здесь, итоги пересчитаются сами
  img/                  логотип и фото. Фото боулов: shrimp.jpg и chicken.jpg (появятся на страницах сами)
  fonts/                шрифт. Сейчас временный Inter, потом заменить на PP Pangram Sans (см. css/style.css)

QR-коды
  1. Выложить сайт (например, Netlify) и получить постоянный адрес.
  2. Открыть qr.html на выложенном сайте, вписать адрес, скачать два QR.
  3. Печатать только после того, как адрес окончательный.
